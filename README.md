# Recipe Sharing App

A recipe-sharing application developed using two different AWS architectures.

## Project Versions

| Feature | Chapter 3 | Chapter 4 |
|---|---|---|
| Architecture | EC2-based | Serverless |
| Frontend | React | React |
| Backend | FastAPI on EC2 | AWS Lambda |
| API | Backend API | API Gateway |
| Database | DynamoDB | DynamoDB |
| Authentication | Not implemented | Amazon Cognito |
| Infrastructure | AWS CloudFormation | AWS CloudFormation |

## Chapter 3 — EC2 Architecture

Traditional architecture using React, FastAPI, EC2, DynamoDB, S3 and CloudFront.

## Chapter 4 — Serverless Architecture

Serverless architecture using React, AWS Lambda, API Gateway, DynamoDB, Cognito, S3 and CloudFront.

## Repository Structure

- `chapter3/` — Original EC2-based implementation.
- `chapter4/` — Serverless implementation.
